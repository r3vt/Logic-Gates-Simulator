# 💻 Logic Gates Simulator

A Command Line Interface (CLI) application built in **C** to simulate fundamental and derived digital logic gates. This project demonstrates practical application of boolean algebra, truth tables, and bitwise operations.

## ✨ Features
- **Interactive Inputs:** Accepts binary inputs (0 or 1) from the user.
- **Input Validation:** Prevents invalid entries gracefully.
- **Custom Header:** Features a dynamic ASCII art introduction with a built-in timer (`sleep`).
- **Comprehensive Outputs:** Computes results for AND, OR, NOT, NAND, NOR, XOR, and XNOR gates simultaneously.

## 🛠️ Technologies Used
- **Language:** C
- **Concepts:** Digital Logic Design, Boolean Logic, Bitwise Operators.
